# Расчёт шпильки на изгиб и местного смятия бетона

В репозитории размещены:
- `Расчет_шпильки_и_смятия_бетона.odt` — расчётная записка с редактируемой таблицей исходных данных;
- `Макрос_расчета.bas` — макрос LibreOffice Basic для пересчёта результатов.

## Принятая схема
1. Изгиб консольного участка: P = m·g; M = P·a; W = π·ds³/32; σs = M/W; проверка σs ≤ Rs.
2. Местное смятие бетона на квадратной площадке b×b: Ab = b²; σb = Nb·1000/Ab; проверка σb ≤ Rb.
3. Проверка скалывания/раскалывания бетона не выполняется.

## Важно перед применением
- ds — расчётный диаметр опасного сечения стержня, а не автоматически номинальные 16 мм резьбы.
- b — сторона фактической контактной площадки; не следует автоматически приравнивать её к диаметру шпильки.
- Rs и Rb должны быть подтверждены по марке материалов и применяемой норме.
- Nb = 1,98 кН, b = 16 мм, ds = 12 мм и Rb = 14,5 МПа — предварительные редактируемые значения/допущения. Проверьте их перед расчётом.
- Документ является расчётным шаблоном, а не экспертным заключением.

Макрос подключается отдельно в LibreOffice Writer: **Сервис/Инструменты → Макросы → Управление макросами → Basic**, импортировать файл `.bas` в библиотеку документа и запустить `ПересчитатьРасчет`.
